6. Predicción 
Fallé en la predicción 1. Pensaba que para cargar una web el navegador hacía una sola petición. Pero en realidad hace muchas más porque cada elemento adicional de la página (imágenes, scripts, CSS, anuncios) requiere su propia petición HTTP independiente al servidor.

7. Diferencia entre curl y el navegador
La diferencia principal es que `curl` descarga únicamente el código HTML de la URL principal en formato texto y se detiene; no lee el contenido ni descarga los recursos enlazados (imágenes, CSS). El navegador, en cambio, lee el HTML, detecta qué recursos adicionales necesita para pintar la web completa y lanza peticiones HTTP automáticas para cada uno de ellos (por eso saltó de 1 petición en `curl` a 21 o 100 peticiones en la pestaña Red).
